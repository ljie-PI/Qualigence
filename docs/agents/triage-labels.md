# Triage Labels

The engineering skills use five canonical triage roles. Local Markdown issues store the corresponding string in their `Status:` line.

| Canonical role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgement |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the matching local status exactly.
